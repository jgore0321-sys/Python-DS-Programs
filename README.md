# Python Data Structures Programs

> A collection of Python programs created while learning and practicing Data Structures and Algorithms.

This repository contains practical implementations of fundamental data structures, searching algorithms, and sorting algorithms using Python.

The programs are based on real-world examples such as music playlists, student records, and employee data.

---

## 📚 Programs Included

| Sr. No. | Program | Main Topic | Concepts |
|:---:|---|---|---|
| 1 | `linked_list.py` | Linked List | Node, Singly Linked List, Insertion, Deletion, Traversal, Searching |
| 2 | `Searching.py` | Searching | Linear Search, Binary Search |
| 3 | `sort.py` | Sorting | Quick Sort, Merge Sort, Recursion |
