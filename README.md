# Python Data Structures Programs

> A collection of Python programs created while learning and practicing Data Structures and Algorithms.

This repository contains practical implementations of fundamental data structures, searching algorithms, sorting algorithms, and queue-based applications using Python.

The programs are based on real-world examples such as music playlists, student records, employee data, bank customer token management, text editing, and cinema seat booking.

### 4. Bank Token Queue System — `banktoken.py`

A simple **Bank Customer Token Queue System** demonstrating the working of a queue using Python.

The program assigns a unique token number to each customer and serves customers according to the **FIFO (First In, First Out)** principle.

**Features:**
- Add a new customer
- Automatically assign a token number
- Serve the next customer
- Display waiting customers
- Exit the program

**Concepts covered:**
- Queue
- Enqueue
- Dequeue
- FIFO principle
- Token management
- Python list

---

### 5. Doubly Linked List Text Editor — `double_ll.py`

Implementation of a simple **Text Editor using a Doubly Linked List** in Python.

Each node stores text and maintains references to both the previous and next nodes, allowing traversal in both directions.

**Features:**
- Insert text at the end
- Delete specific text
- Display text from beginning to end
- Search for text
- Display text in reverse order

**Concepts covered:**
- Doubly Linked List
- Node creation
- Previous and next pointers
- Insertion and deletion
- Searching and traversal
- Forward and reverse traversal
- Classes and objects

---

### 6. Cinema Seat Booking System — `cinemahall.py`

A simple **Cinema Seat Booking System** implemented using a two-dimensional Python list.

The program manages a cinema hall with **10 rows and 10 columns**, allowing users to book seats, check availability, and cancel bookings.

**Features:**
- Display all cinema seats
- Book an available seat
- Check seat availability
- Cancel a booking
- Prevent booking an already-booked seat
- Validate row and column numbers
- Exit the program

**Concepts covered:**
- Two-dimensional lists
- Nested loops
- Functions
- Conditional statements
- Indexing
- Input validation
- Menu-driven programming

The program represents available seats using `0` and booked seats using `1`.
